Web Development & Process Automation

1. E-Laundry Management System with Status Tracking (BubbleLink)

Peran: Full Stack Developer (Kelompok 1) | Metodologi: Waterfall | Tech Stack: PHP Native (PDO), MySQL, HTML5, CSS3

BubbleLink dikembangkan untuk menyelesaikan permasalahan efisiensi operasional pada bisnis jasa laundry konvensional, seperti pencatatan transaksi manual yang rentan hilang serta minimnya transparansi status pencucian bagi pelanggan. Sistem berbasis web ini menghubungkan 3 hak akses utama (Pelanggan, Admin Kasir, dan Kurir) dalam satu basis data terintegrasi, mencakup alur pemesanan online, verifikasi pembayaran, hingga penugasan jemput-antar pakaian secara real-time.

Fitur Utama & Keunggulan Sistem:
  • Live Status Tracking: Pelanggan dapat melacak tahapan cuci (Diterima, Dicuci, Dijemur, Disetrika, Siap Diantar) secara transparan.
  • Kalkulasi Biaya & Print Label: Perhitungan otomatis berdasarkan bobot/paket cuci serta pembuatan label identitas kantong cuci untuk mencegah pakaian tertukar.
Kontribusi Teknis & Arsitektur:
  • Merancang skema relasi basis data MySQL (ERD) dan mengimplementasikan keamanan transaksi data menggunakan PHP PDO.
  • Menyusun antarmuka responsif pengguna (User Dashboard) serta alur autentikasi multi-user yang aman.

Data Science & Machine Learning

2. Prediksi Performa Akademik Mahasiswa ITPLN

Peran: Data Analyst / ML Developer (Kelompok 4) | Tech: Python (Pandas, Scikit-Learn, Seaborn), Google Colab, Streamlit Dashboard

Penelitian ini bertujuan untuk memprediksi tingkat performa akademik mahasiswa (kategori High, Medium, Low) berdasarkan analisis variabel pola kebiasaan harian seperti durasi belajar efektif, kualitas tidur, frekuensi olahraga, screen time media sosial, dan tingkat stres mental. Melalui pendekatan supervised learning, model AI ini membantu memberikan deteksi dini serta rekomendasi gaya hidup yang seimbang bagi mahasiswa.

Analisis Data & Perbandingan Algoritma:
  • Melakukan tahapan Data Cleaning, Normalisasi Data, serta Exploratory Data Analysis (EDA) menggunakan Matplotlib/Seaborn.
  • Algoritma Logistic Regression terbukti menjadi model terbaik dengan tingkat akurasi mencapai 79,5% (≈80%), mengungguli Random Forest (73,5%).
Implementasi Web Interactive Dashboard:
  • Mengintegrasikan model Machine Learning yang telah dilatih ke dalam aplikasi antarmuka web Streamlit.
  • Menampilkan kalkulasi persentase Confidence Level prediksi serta menghasilkan saran/tips rekomendasi harian secara otomatis.

Internet of Things (IoT) & Embedded Systems

3. Smart Energy Monitoring & Real-Time Cost Estimation System

Peran: Hardware Assembly, Circuit Design & Tech Documentation (Kelompok 2) | Tech: ESP32, PZEM-004T, DHT11, Relay, MQTT (HiveMQ Cloud), Flask API, Tailwind CSS

Proyek perangkat keras dan lunak IoT ini dirancang untuk memantau konsumsi energi listrik serta suhu lingkungan panel secara real-time. Sistem ini mengintegrasikan mikrokontroler ESP32 dengan sensor daya presisi tinggi untuk menghitung beban biaya listrik (Rupiah) secara konsisten sekaligus menyediakan mekanisme pertahanan/keamanan perangkat dari risiko beban berlebih (overload) atau bahaya overheat.

Pembacaan Sensor & Proteksi Otomatis:
  • Pengukuran akurat parameter Tegangan (V), Arus (A), Daya (W), Energi (kWh), dan Suhu (°C).
  • Fitur Automatic Safety Cut-off Relay yang memutus arus listrik secara cepat ketika beban melebihi ambang batas aman (≥500W) atau suhu berlebih (>45°C).
Cloud Connectivity & Web Monitoring:
  • Pengiriman telemetri data nirkabel dari ESP32 menuju broker HiveMQ Cloud berbasis protokol MQTT.
  • Visualisasi data grafik daya listrik real-time dan kalkulasi estimasi tagihan listrik bulanan pada Web Dashboard interaktif.

UI/UX Design & User Research

4. Analisis & Perancangan Aplikasi F-KELANA (Financial Management UI/UX)

Peran: UI/UX Designer (Kelompok 5) | Metodologi: Design Thinking | Tools: Figma (Wireframe & High-Fidelity Prototype), Usability Testing

F-KELANA merupakan hasil perancangan antarmuka pengguna (UI/UX) aplikasi manajemen keuangan pribadi berbasis mobile yang dirancang khusus untuk memenuhi kebutuhan mahasiswa dan first-jobber (Gen-Z). Proyek ini berfokus pada penyelesaian masalah kebiasaan belanja impulsif serta kesulitan pencatatan anggaran harian melalui pengalaman pengguna yang intuitif, cepat, dan interaktif.

Fitur Unggulan Antarmuka:
  • One-Page Quick Input Form: Memudahkan pencatatan pemasukan/pengeluaran harian kurang dari 5 detik.
  • Visualisasi Dompet Terpusat & Budget Warning: Progress Bar batas anggaran dengan indikator peringatan visual saat pengeluaran mendekati limit harian.
Tahapan Iterasi Metodologi Design Thinking:
  • Tahap Empathize & Define: Wawancara pengguna untuk mengidentifikasi pain points keuangan mahasiswa.
  • Tahap Wireframing & Prototyping: Mengembangkan alur Low-Fidelity hingga desain interaktif High-Fidelity berbasis design system di Figma.
